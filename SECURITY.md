# Security Policy

## Supported Versions

Only the latest release / `main` branch of Melo receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Melo (such as token leak issues, CORS misconfigurations, or XSS vectors), please report it responsibly.

**Please do NOT create a public GitHub Issue for security vulnerabilities.**

Instead, please send an email or submit a private security disclosure via GitHub Security Advisories.
